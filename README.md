# Portfolio d'Alexandre Zapolski

Portfolio personnel présentant mon parcours, mes compétences et mes projets en développement web.

## À propos

Je suis Alexandre Zapolski, développeur web junior en formation en Bachelor Développement Web.

Ce portfolio me permet de présenter mon évolution, mes compétences techniques et les projets que je réalise dans le cadre de ma formation et de mon apprentissage personnel.

## Technologies utilisées

- **HTML5** — structure et sémantique
- **CSS3** — mise en page, responsive design et thèmes
- **JavaScript** — interactions et fonctionnalités dynamiques
- **Git / GitHub** — gestion du code source et versionnement

## Fonctionnalités

Le portfolio comprend notamment :

- une présentation de mon parcours ;
- une section dédiée à mes compétences ;
- une présentation de mes projets ;
- un formulaire de contact fonctionnel ;
- un changement de thème clair/sombre ;
- une interface responsive adaptée aux différents écrans ;
- des améliorations liées à l'accessibilité et à l'expérience utilisateur.

## Déploiement

Le portfolio est un site statique hébergé avec **GitHub Pages**.

Les fichiers HTML, CSS et JavaScript sont directement servis par GitHub Pages, sans serveur backend nécessaire pour le fonctionnement du portfolio.
